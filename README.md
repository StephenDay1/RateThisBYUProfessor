# RateThisBYUProfessor
A simple Chrome extension adding integration of Rate My Professors into BYU's MyMAP!

## Easily view scores and other information from [Rate My Professors](https://www.ratemyprofessors.com/) within MyMAP itself

![Image](./src/images/ClassList-1.1-1280x800.png)

## Easily pick out your schedule for next semester

![Image](./src/images/ChooseASection-1.1-1280x800.png)

## We aren't able to find every professor automatically
If we can't find it, you're still only one click away from searching for them yourself on the Rate My Professors page.
